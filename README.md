The portfolio is fully responsive with breakpoints for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (<768px)

## 🔧 Customization

To customize this portfolio:

1. **Update content**: Modify text in HTML sections
2. **Change colors**: Edit CSS variables in `:root`
3. **Add projects**: Update `projectsData` array in JavaScript
4. **Replace images**: Update image paths in `<img>` tags
